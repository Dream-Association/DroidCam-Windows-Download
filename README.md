## 🧠 Overview

**DroidCam** allows a supported smartphone to function as a camera source for a Windows computer. The mobile device handles image capture while the desktop client transfers the camera feed into compatible PC applications, creating an alternative setup for meetings, broadcasts, recordings, and everyday video communication.

The software supports different connection approaches, including wireless networking and USB, so users can choose a configuration that suits their equipment and workspace. Depending on the smartphone and client configuration, the phone's microphone can also be used as an audio source alongside the transmitted camera image.

With access to supported camera adjustments and desktop integration, **DroidCam** can turn an existing smartphone into a flexible video tool. It can be incorporated into communication software, streaming applications, recording programs, and other Windows environments that recognize its camera output.

## Additional Information for Windows Users

The **DroidCam** workflow relies on communication between the smartphone and its Windows companion client. The phone captures the video, and the desktop component receives the stream so that compatible applications can access it as a camera source. This arrangement allows users to make use of hardware they may already have instead of relying solely on a built-in computer camera.

For flexible setups, Wi-Fi can make it easier to position the smartphone away from the PC, which can be useful when changing camera angles or mounting the phone in a convenient location. A USB connection provides a wired alternative for users who prefer connecting the two devices directly.

The application can be incorporated into many different Windows activities. A smartphone can be positioned for video conferences, demonstrations, livestreams, recordings, online lessons, or other camera-based tasks. Supported image controls can then be used to adjust the appearance and orientation of the video according to the requirements of the particular setup.
